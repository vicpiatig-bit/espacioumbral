# Espacio Umbral 

Quiero construir la landing page de Umbral directamente en este proyecto de Lovable.

IMPORTANTE:

No existe código previo de esta landing dentro de este proyecto. Quiero construirla desde cero en Lovable.

Adjunto:

1. Una captura de la landing que hice previamente, que debe utilizarse como referencia visual.

2. Las fotografías originales que quiero utilizar en la nueva landing.

La captura NO debe copiarse literalmente ni reproducirse pixel por pixel. Utilizala como referencia de dirección visual, composición, ritmo, jerarquía y sensación general.

Las fotografías adjuntas son los assets reales y definitivos del proyecto. Utilizá esas fotografías y no las reemplaces por imágenes de stock ni generes imágenes alternativas.

El Project Knowledge contiene la identidad, tono, estética y reglas permanentes de Umbral. Respetalo.

# Objetivo

Construir una landing page premium para Umbral, un estudio de yoga, meditación y masajes ubicado en Palermo Hollywood, Buenos Aires.

El objetivo principal de la landing es que una persona:

1. descubra qué es Umbral;

2. conecte emocionalmente con su propuesta;

3. entienda sus diferentes experiencias;

4. conozca el espacio;

5. y finalmente contacte por WhatsApp.

Umbral no debe sentirse como un gimnasio, un spa tradicional ni una web genérica de yoga.

Debe sentirse como un refugio dentro de la ciudad.

La experiencia conceptual es:

RUIDO → PAUSA → UMBRAL → CUERPO → MENTE → EXPERIENCIA → PRESENCIA → CONTACTO

# Dirección creativa

Usá la captura adjunta como referencia de dirección visual.

Quiero conservar y desarrollar sus principales características:

- estética minimalista;

- diseño editorial;

- elegancia;

- serenidad;

- espiritualidad sutil;

- mucho espacio negativo;

- composición asimétrica;

- tipografía serif protagonista;

- fotografías grandes y atmosféricas;

- paleta crema, blanco roto y tonos neutros;

- sensación cálida y sofisticada.

No copies la referencia literalmente.

Analizá qué funciona visualmente en ella y construí una versión más refinada, coherente y funcional para Umbral.

La página debe sentirse diseñada por un director de arte, no generada a partir de una plantilla de wellness.

# Narrativa

La landing debe contar una única historia.

El visitante primero debe reconocer el ritmo y ruido de la vida cotidiana.

Después debe descubrir la posibilidad de hacer una pausa.

Luego debe conocer Umbral como ese espacio de transición.

Después debe descubrir las tres formas principales de entrar en la experiencia:

Yoga → volver al cuerpo.

Meditación → encontrar silencio.

Masajes → soltar el cuerpo.

Finalmente debe conocer el espacio, elegir qué necesita y encontrar una invitación clara para contactar.

No quiero una colección de secciones desconectadas.

Cada sección debe conducir naturalmente a la siguiente.

# Estructura

Construí una landing de una sola página con esta estructura:

1. Header

2. Hero

3. Pausa / ritmo de la ciudad

4. Qué es Umbral

5. Yoga

6. Meditación

7. Masajes

8. El espacio

9. ¿Qué necesitás hoy?

10. Filosofía / testimonio

11. Ubicación y horarios

12. CTA final

13. Footer

# Fotografías

Las fotografías adjuntas son las imágenes definitivas proporcionadas por el cliente.

Utilizarlas como parte central de la dirección artística.

No:

- utilizar stock photography;

- reemplazarlas por imágenes generadas;

- agregar fotografías genéricas;

- aplicar filtros fuertes;

- alterar artificialmente sus colores.

Elegir qué fotografía corresponde a cada sección según su contenido y composición.

Priorizar fotografías con buen espacio negativo cuando se utilicen junto a texto.

En mobile, adaptar los crops cuidadosamente para conservar el sujeto principal y la intención de la imagen.

# Diseño

Mantener una estética:

- minimalista;

- editorial;

- elegante;

- serena;

- cálida;

- espiritual pero contemporánea.

Paleta:

- blanco roto;

- crema;

- arena;

- beige;

- marrón suave;

- negro cálido.

Utilizar una serif editorial elegante para titulares y una sans-serif limpia para textos funcionales.

No utilizar más de dos familias tipográficas.

Utilizar mucho espacio negativo.

Mantener composiciones asimétricas equilibradas.

Evitar:

- gradientes fuertes;

- colores saturados;

- verde wellness genérico;

- violeta brillante;

- glassmorphism;

- exceso de sombras;

- exceso de bordes;

- exceso de cards;

- iconografía decorativa innecesaria.

# UX

La página debe ser fácil de recorrer y comprender.

Priorizar una jerarquía clara.

El usuario debe poder entender la propuesta simplemente recorriendo los titulares.

Reducir decisiones innecesarias.

El CTA principal debe ser siempre WhatsApp.

No llenar cada sección con botones.

Los botones deben ser grandes y cómodos para touch.

La conversión debe sentirse como una invitación natural, no como una venta agresiva.

# Responsive

Diseñar cuidadosamente para:

- desktop;

- tablet;

- mobile.

No simplemente comprimir el diseño desktop.

En mobile:

- mantener titulares expresivos;

- mantener suficiente espacio negativo;

- apilar correctamente las composiciones;

- conservar buenos crops de fotografía;

- mantener navegación simple;

- hacer WhatsApp fácilmente accesible;

- mantener buena legibilidad.

# Animaciones

Utilizar únicamente motion sutil:

- fade-in;

- pequeños desplazamientos;

- transiciones suaves;

- apariciones progresivas;

- hover delicado.

El movimiento debe transmitir calma.

No utilizar:

- rebotes;

- efectos rápidos;

- parallax agresivo;

- animaciones llamativas;

- exceso de movimiento.
